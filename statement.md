# Project Statement

## Project Title

Daily Expense Tracker

## Problem Statement

People often have many daily expenses and may find it difficult to keep track of them.

The Daily Expense Tracker provides a simple way to record and manage expenses using Python.

## Scope of the Project

The project is used to manage basic daily expenses.

The program can:

- Add expenses
- View all expenses
- Calculate total expenses
- Calculate average expenses
- Clear all expenses

The expenses are stored only while the program is running.

## Target Users

This project can be used by:

- Students
- Beginners learning Python
- People who want to keep a simple record of expenses

## High-Level Features

### 1. Add Expense

The user can enter an expense amount and save it in the program.

### 2. View Expenses

The user can see all the expenses that have been added.

### 3. Calculate Total

The program calculates the total of all recorded expenses.

### 4. Calculate Average

The program calculates the average expense.

### 5. Clear Expenses

The user can remove all recorded expenses.

### 6. Menu System

The program uses a simple menu so the user can easily select an option.
